# Spice Stream

Spice Stream is a Twitter-style recipe-sharing feed where users can share their favorite recipes. This app allows users to post and view recipes in a simple, interactive feed. The app can be deployed using AWS services and Docker, with the infrastructure managed by CloudFormation.

## Features

- Share recipes with ingredients and instructions.
- View a timeline of shared recipes.

## Tech Stack

- **Frontend**: React, JavaScript
- **Backend**: C#, ASP.NET Core
- **Database**: MySQL
- **Deployment**: AWS (EC2, ECS, RDS, CloudFormation, etc.)
- **Containerization**: Docker
- **Version Control**: Git
